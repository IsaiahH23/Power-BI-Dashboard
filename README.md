# Quality Data Analyst Power BI Dashboard

This Power BI project was created to demonstrate capabilities in transforming raw data into actionable insights, tailored for roles involving cross-departmental collaboration, data quality, and performance metrics.

## 📊 Dashboard Features
- **Interactive KPIs** for Planned vs. Actual performance
- **Department and Project-level filtering** (Finance, Public Utilities, HR, Operations)
- **Metric-focused visualizations** (Cost, Accuracy, Timeliness, Compliance)
- **Data Quality Score tracking** over time
- Slicers and filters to enable flexible cross-functional reporting

## 🧰 Tools Used
- Power BI Desktop
- Microsoft Excel (mock data preparation)
- SQL (simulated through backend logic)
- GitHub for version control and portfolio display

## 📁 Files Included
- `Quality_Data_Analyst_Dashboard.pbix`: Power BI dashboard file
- `quality_data_dashboard_dataset.csv`: Mock dataset used in the dashboard
- `README.md`: Documentation for project

## 📂 How to Open the Project
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Clone this repository or download the files manually.
3. Open `Quality_Data_Analyst_Dashboard.pbix` in Power BI Desktop.
4. Explore the report, apply filters, or modify visuals to fit your needs.

## 🔍 Use Case
This project demonstrates:
- Translating business needs into technical solutions
- Supporting strategic and operational planning
- Collaborating across departments through data-driven insights
